# Personal-site content

Apply this skill to every task performed by a GPT model in this repository. If a task does not affect public-facing writing, layout, or visual direction, it requires no additional action.

For public pages, the person is the primary subject, not a software portfolio. Use content that is present in the repository or CMS. Do not invent marketing copy to fill visual space or explanatory microcopy for obvious structure.

Do not introduce these phrases or patterns unless the user or a content source supplies them:

- "Selected Work"
- "Explore"
- "Things that..."
- "More than..."
- "Not just X, but Y"
- "Where X meets Y"
- vague or poetic section slogans

Prefer concrete section names such as Projects, Writing, Publications, and Now. Prefer real photos, artifacts, screenshots, documents, dates, titles, and content before decorative abstractions.

Create visual interest through composition, motion, scale, cropping, rhythm, and real media. Do not rely on invented copy, bento grids, generic cards, glows, gradients, or agency-style slogans.

If CMS globals exist, inspect and use them before inventing page structure. Preserve unknowns rather than manufacturing missing information.

Before finishing, ask yourself: "Could this be a generic agency/template site if I replaced the name?" If yes, iterate until the page is specific to the person and their real material.
