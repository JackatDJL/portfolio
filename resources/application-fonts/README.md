# Anschreiben fonts

Unmodified Noto Sans SemiCondensed Regular, Bold and Italic from
[notofonts/noto-fonts](https://github.com/notofonts/noto-fonts/tree/ffebf8c1ee449e544955a7e813c54f9b73848eac/hinted/ttf/NotoSans),
commit `ffebf8c1ee449e544955a7e813c54f9b73848eac`.

These SIL Open Font License assets are used only by the Anschreiben template.
They are separate from `resources/fonts` so the CV fonts and their cache inputs
remain unchanged. See `OFL.txt` for the license.
